# 客脉图 · v1.3.1

> **客户成脉，往来成图**
>
> 一款运行在安卓手机上的「客户关系思维导图 + 拜访清单」。把每位客户当作导图上的一个节点，
> 按"谁介绍了谁"的层级自动铺开成一张可以无限延展的图；同时按办卡时间自动生成拜访任务。

## 二、怎么装到手机上

1. 把 `工具/客脉图_v1.3.0_debug.apk` 传到手机，点击安装。
2. 系统提示"不允许安装未知来源应用"时，给**文件管理器**开启"允许安装未知应用"权限后继续。
3. 装好后桌面会出现「客脉图」图标。

> **首次打开是干净的空画布**，没有任何演示数据。点中间那个「新建第一位客户」就能开始。

**权限**：不申请网络权限、不申请存储权限。只有拜访提醒用到两个权限：
`通知`（Android 13+ 首次用到时问一次）、`开机自启`（系统自动授予，无弹窗）。

## 三、v1.3 改了什么

### 1. 日期选择器改成中文了

之前日期弹窗是英文的（April / Mon / OK…），对不习惯英文的人很不友好。现在**整块都是中文**：
「选择日期 / 2026年8月 / 一 二 三 四 五 六 日 / 取消 确定」。

做法上说一句：这个弹窗是 Material3 组件自带的，它的月份、星期会跟随系统语言，
但标题那一行是库里写死的英文字符串。所以除了把应用语言设成中文，
我还**直接给标题传了中文文案**，彻底不依赖库的本地化。

### 2. 设置里新增「语言」

设置 → 外观 → **语言**：简体中文（默认）/ English。

- 切换后会**重建界面**，日期选择器等系统组件也跟着变
- ⚠️ **当前状态：英文只覆盖系统级文案（日期选择器、时间格式等），应用内的界面文字仍是中文。**
  把所有界面文字翻译成英文是一次独立的、不小的改动（涉及 200 多条文案），
  需要的话我再单独做一轮。

### 3. 首页左上角：图标 + 名称 + 宣传语

参考你给的念痕那张图，顶部左上角现在是：

```
┌──────────────────────────────────────────┐
│ [图标]  客脉图                 🔍  ?  ⚙️ │
│         客户成脉，往来成图               │
│                            [ ☰ 拜访 6 ]  │
└──────────────────────────────────────────┘
```

### 4. 去掉了「＋」按钮

右下角现在只剩「适应全图」。

理由和你判断的一致：「＋」建的是**根客户**，建完还得填介绍人，并不是常用路径。
现在新增客户走两条路：

- **第一次**：空画布中间的「新建第一位客户」
- **之后**：选中卡片 → 底部操作条的「**加下级**」（这位客户介绍来的人）/「**加同级**」（和它同一个介绍人的客户）

操作指南里也按这个改了，重点讲「加下级 / 加同级」，不再介绍「＋」。

### 5. 选中态大幅强化

之前选中和没选中几乎看不出来。现在选中的卡片有**四重区分**：

| 变化 | 效果 |
| --- | --- |
| 外圈光晕 | 卡片外围一圈半透明主题色，像被"点亮"了 |
| 描边加粗 | 从 1.2px 提到 3.4px |
| 填充染色 | 卡片底色向该节点的颜色明显偏移 |
| 整体放大 | 宽 3%、高 6% |

### 6. 卡片按「脉络深度」分色

按你说的：**第 1 层一个颜色、第 2 层一个颜色、第 3 层一个颜色**，越往下越浅。

| 深度 | 颜色 |
| --- | --- |
| 第 1 层（根客户） | 深青瓷 |
| 第 2 层 | 靛蓝 |
| 第 3 层 | 紫罗兰 |
| 第 4 层 | 玫紫 |
| 第 5 层 | 琥珀 |
| 第 6 层 | 橄榄绿 |

**同时保留了你原来那套**：设置 → 外观 → **卡片配色**，可以切回「按客户家族」（同一棵子树一个色相）。
两套随时换，看你哪个用着顺。

### 7. 应用图标（占位版）

正式图标等 image2.5 明天做好再换。现在这个是**矢量画的占位图标**，圆形 / 方圆 / 圆角方形三种遮罩都好看：

- 青瓷蓝绿斜向渐变底 + 左上柔光
- 白色三点脉络图（上级节点略大，旁边一点暖色）
- 已按 Android 自适应图标规范把内容收在中央 66×66 安全区内

预览图在 [`工具/应用图标设计素材/00-占位图标-三种遮罩预览.png`](../工具/应用图标设计素材/00-占位图标-三种遮罩预览.png)。

## 四、功能全景

### 导图

| 功能 | 说明 |
| --- | --- |
| **无限画布** | 单指拖动平移，双指捏合缩放（30%~250%），右下角「适应全图」 |
| **思维导图** | 竖向或横向自选；父节点自动居中于子节点；深度宽度都不设上限 |
| **多个根客户** | 互不相关的客户并排，各自带一整棵子树 |
| **卡片配色** | 按脉络深度 / 按客户家族，二选一 |
| **客户字段** | 名称、办卡时间、产品（多选）、备注、自定义信息（条数不限） |
| **字段名可改** | 三个内置字段的名字都能改成任何行业的叫法 |
| **介绍关系** | 加下级 / 加同级 / 改介绍人；自动拦截成环 |
| **产品库** | 统一维护，可增删改、排序、停用；删除产品不丢数据 |
| **搜索** | 搜客户名称、产品、备注、自定义信息；点结果自动飞到该节点 |
| **折叠子树** | 点卡片下方的「n 位下级」收起整棵子树；状态会保存 |
| **操作指南** | 顶部 ? 图标，6 章带序号标注的真实界面截图 |

### 拜访提醒

| 功能 | 说明 |
| --- | --- |
| **拜访清单入口** | 顶部「拜访 n」入口带未完成数量角标，**角标永远准确** |
| **自动清单** | 「新客户每周拜访」按办卡时间自动生成，每周一重置本周已拜访状态 |
| **自建清单** | 想建几张建几张，名字随你起 |
| **清单项** | 客户名称、计划回访时间、回访内容，都可留空 |
| **快速标记** | 点左边的圈＝用今天标记已拜访；再点一下可取消 |
| **拜访历史** | 每次标记留一条记录，条目详情里能看 |
| **三层提醒** | ① 顶部角标 ② 打开应用时的横幅 ③ 每周一 09:00 系统通知 |
| **提醒可配置** | 开关、频率、提醒日、提醒时间、新客户判定（3/6/12 个月） |
| **通知自检** | 4 项检查 + 一键测试通知 + 按机型品牌自动匹配厂商后台设置路径 |

## 五、通知为什么可能不响

系统通知**可能被手机的省电策略拦住**（小米 / 华为 / OPPO / vivo 后台管控都很严）。
应用里做了「通知是否正常？」自检页（设置 → 提醒），把原因逐条摊开，并按品牌给出路径：

| 品牌 | 设置路径 |
| --- | --- |
| **VIVO / iQOO** | 设置 → 电池 → 后台耗电管理 → 客脉图 → **允许后台高耗电** |
| 小米 / Redmi | 设置 → 应用设置 → 客脉图 → 省电策略 → **无限制**；并开启**自启动** |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → 客脉图 → 关闭"自动管理" → 勾选**允许自启动/关联启动/后台活动** |
| OPPO / 一加 / realme | 设置 → 电池 → 应用耗电管理 → 客脉图 → 允许**后台运行** + **自动启动** |
| 三星 | 设置 → 电池 → 后台使用限制 → 把客脉图从"休眠应用"中移除 |

> **底线保证**：不管通知响不响，**顶部角标永远是准的**。打开应用就一定看得到本周名单。

## 七、工程结构

```
KemaiTu/app/src/main/java/com/kemai/app/
├── model/Models.kt              数据模型 + 字段名/脉络方向/配色方式/语言等枚举
├── data/                        JsonCodec + AppRepository
├── reminder/                    ReminderScheduler + ReminderReceiver + BootReceiver
├── ui/
│   ├── theme/                   配色（深度/家族两套）、字号、各类 CompositionLocal
│   ├── canvas/                  TreeLayout（竖向/横向双方向）+ CanvasScreen
│   ├── components/              通用小部件 + KemaiIcon（自绘图标入口）
│   ├── editor/ products/ search/ visits/ settings/ guide/
├── util/Dates.kt
├── KemaiApplication.kt
└── MainActivity.kt
```

**技术要点**：纯 Kotlin + Jetpack Compose + Material 3；**零第三方依赖**、**零网络权限**；
数据存本机单个 JSON 文件；画布用 `Canvas` + `TextMeasurer` 手绘配合视口裁剪；
提醒用系统自带 `AlarmManager`（非精确闹钟，不需要精确闹钟权限）。

## 八、已知限制

| 项 | 说明 |
| --- | --- |
| **英文界面未完成** | 语言选项目前只切换系统级文案（日期选择器、时间格式）。应用内 200 多条界面文字仍是中文，需要单独做一轮。 |
| **模拟器测不出真实流畅度** | 模拟器是 SwiftShader 纯 CPU 软件渲染（无 GPU）。空画布光画背景网格就要 34ms/帧，200 个客户 48ms —— 开销绝大部分是软件光栅化。**手感需要真机确认**。 |
| **系统通知在真机上的到达** | 模拟器上验证了通知能发出、闹钟能排进系统队列；厂商 ROM 的后台管控只能真机验证。 |
| 只支持竖屏 | 按竖屏设计，横屏不崩但没专门适配 |
| 最低系统版本 | Android 8.0（API 26） |
| 单一介绍人 | 一个客户只能有一个介绍人 |
| 只记一次办卡时间 | 多次办卡不单独留痕，只体现为产品标签的累加 |
| 周重置的时机 | "每周一重置"在**打开应用时**检查执行；整周没打开会在下次打开时补上 |
