## 四、最该重点测的 3 件事 ★

真机才能测出来的就这三条，其余在模拟器上我已经验证过了。

### ★ 1. 通知能不能弹出来

**路径**：设置 → 提醒 → **「通知是否正常？」**

先看那 4 项检查：
- **通知权限** —— 应该是 ✓
- **电池优化** —— 如果是 ⚠️，点「去设置」把客脉图设为**不受限制**
- **厂商后台策略** —— 这一项显示 ❓ 是正常的（系统不开放读取），按下面给的步骤手动设置一次
- **下次提醒时间** —— 应该显示某个未来时间

然后按 **「发一条测试通知」** —— 通知栏应该**马上**出现「客脉图 · 拜访提醒」。

> 如果这一步就没反应 → 说明通道被拦了。回到上面按你的手机品牌设置：
> **VIVO / iQOO**：设置 → 电池 → 后台耗电管理 → 客脉图 → **允许后台高耗电**
> **小米 / Redmi**：设置 → 应用设置 → 客脉图 → 省电策略 → **无限制**，并开启**自启动**
> **华为 / 荣耀**：设置 → 应用 → 应用启动管理 → 客脉图 → 关自动管理，勾选**允许自启动/关联启动/后台活动**
> **OPPO / 一加**：设置 → 电池 → 应用耗电管理 → 客脉图 → 允许**后台运行** + **自动启动**

### ★ 2. 闹钟到底会不会自己响

同一个页面，按下面的 **「测试闹钟（1 分钟后触发）」**，然后把手机**放到一边别碰**。

- 通知栏应该在 **1～5 分钟内**自己弹出「当前有 N 位客户待拜访，点开看看吧」
- **注意**：用的是系统非精确闹钟（为了不额外要"精确闹钟"权限、也更省电），
  实际触发可能比设定晚几分钟 —— 我实测晚了约 2.5 分钟。**这是正常的，不是 bug。**

> 这一条测的是「闹钟 → 广播 → 通知」整条链路。
> 响过之后应用会自动把正式的每周提醒接回去（自检页的"下次提醒时间"会恢复）。

### ★ 3. 真机上的手感

模拟器是**纯 CPU 软件渲染（没有 GPU）**，所以我量到的帧时间不代表真机。真机上重点感受：

- 单指拖画布、双指缩放，跟不跟手
- 客户多了（可以先建 30～50 个）之后还流不流畅
- 卡片点击、长按、折叠的响应

## 六、验证完之后

确认没问题就可以开始录真实客户了。建议顺序：

1. 先把**产品库**里灌上你朋友 A 实际在用的产品（设置 → 产品库管理）
2. 如果他们的字段叫法不是"客户/办卡/产品"，先到**设置 → 字段名称**改成实际叫法
3. 再把已有的客户录进去（第一位用中间那个按钮，之后的都用「加下级 / 加同级」）
4. 录完到**设置 → 导出备份**存一份，以后换手机/误删都能救回来

> 演示数据的事再强调一次：**出厂是空应用**，不会有任何跟你朋友业务无关的内容。
> 你现在模拟器里看到的"客户A/B/C/D、金卡/白金卡"是我为了截图和测试造的，手机上不会有。
