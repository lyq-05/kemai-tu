## 🚀 本次更新

### 修复：桌面图标和首页那个不是一套

首页左上角的品牌标记（图 1）和桌面图标（图 2）**看起来像两个应用**，问题出在三处：

| | 旧桌面图标 | 现在 |
| --- | --- | --- |
| 小点 | 根节点旁多了个暖色小点（首页那个没有） | **去掉**，两边完全同一套图形 |
| 尺寸 | 图形约 58×63，快顶到自适应图标的安全区边缘，显得挤 | **缩到约 45×48**，四周留足余量 |
| 底色 | 自己另配的深色渐变 `#57A89F → #1E4E4A`，越往下越深 | **明亮青绿** `#8AD3CB → #63B3AB`，对齐首页那个 |

底色为什么是明亮的青绿：首页那个标记用的是**深色模式强调色** `QingCiDark` = `#7FC9C2`，
本身就是明亮青绿。桌面图标之前用的是浅色模式强调色那一路（`#2F6E6A`，偏深），
所以看着"莫名暗了一截"。

现在两处**用同一套几何、同一个色系**，只是图标按自适应图标规范做了安全区留白。

## ⚠️ 升级说明

覆盖安装后如果桌面图标没变，是启动器缓存了旧图标 —— **重启一下手机**，或者把图标从桌面删掉重新拖一个出来即可。
