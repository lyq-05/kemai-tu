## 🚀 本次更新

### 1.「通知自检与修复」→「通知设置」，测试看板全部收起

之前的页面里混了大量开发调试用的内容，正式版给普通用户看并不合适。现在只剩 **4 项真正需要用户操作的检查**：

| 检查项 | 作用 |
| --- | --- |
| 通知权限 | 没开就点「去开启」 |
| 系统电池优化 | 加入 Doze 白名单，防后台被冻结 |
| 精确闹钟 | **提醒能不能按时响的关键**，去系统「闹钟与提醒」打开 |
| 厂商后台策略 | 按手机品牌显示对应的设置路径 |

**已从正式版界面移除**：「通知能不能弹出来」「下次提醒时间」「系统怎么看待本应用」
「本次排定」「上一次闹钟」「降级原因」「发一条测试通知」「1 分钟后发一条通知」。

> **保底手段**：连点页面标题 **7 次**，诊断区会重新出现。
> 万一有朋友的手机收不到通知，让他在电话里连点 7 下，就能把关键数据念给你听 ——
> 不用为了排查专门做一个版本。

### 2. 提醒时间改为任意分钟

之前只能从 **08:00 / 09:00 / 12:00 / 18:00 / 20:00** 里挑一个。现在点「提醒时间」会弹出
系统的时分选择器，**精确到分钟**，改完立刻按新时间重新排定。

顺带的好处：想验证提醒到底通不通，直接设一个一两分钟后的时间就行，不用再等。

> 数据格式新增 `notifyMinute` 字段。**旧版本的数据会自动按 0 分读取**，已有的提醒设置不受影响。

### 3. 首次引导弹窗文案同步

去掉了「通知能否弹出」这个已经不存在的说法。
