## 🚀 本次更新

### 重做：操作指南配图

之前的配图是"整行半透明高亮带"，框不住具体要点的那个控件，看着糊。现在改成了：

- **紧跟控件边界的蓝色描边框** —— 要点哪个按钮，框就套在哪个按钮上
- **橙色序号圆点压在框的左上角**，白字数字
- 全部是**应用真实界面的整屏截图**

六章配图共 **27 个标注框**，坐标不是估的 —— 我写了个探测脚本
（`工具/_probe_ui.py`）从截图里逐行扫像素，量出每个控件的真实边界，再照着画。

### 新增：拜访清单里「已拜访」可以收起

之前打过勾的客户会一直堆在清单里，越用越长。现在：

- 打过勾的自动归到 **「已拜访 n 位」** 这一组
- **默认收起**，点一下才展开
- 右边显示「展开 / 收起」和箭头，状态一目了然

### 新增：客户名片里能直接看拜访历史

之前只能在拜访清单的条目详情里看历史。现在打开任一客户的编辑面板，
底部多了一块只读的 **「拜访历史」**：

```
拜访历史                          共 3 次
  ✓ 已拜访 9月30日   计划 9月28日
    聊了新出的白金卡，说下个月再约
  ─────────────────────────────
  ✓ 已拜访 8月12日
    送了对账单，客户问了额度的事
```

每条记录都带**实际拜访日期、计划回访时间、回访内容**，
不用再回头翻清单。这块是只读的，记录来自你在清单里打的勾。
