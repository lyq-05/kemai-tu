## ⚠️ 重要：这个版本的签名换了

之前的版本用的是 **debug 签名**，这个正式版换成了**独立生成的正式签名密钥**。

**后果**：签名不同，Android 不允许覆盖安装。

- **新用户**：直接装，没影响
- **已装过旧版本（v1.8.x 及更早）**：必须先卸载再装，**卸载会清空数据**

### 装过旧版的，按这个顺序保住数据

1. 打开旧版 → **设置 → 数据 → 导出备份**（存到手机里）
2. 卸载旧版
3. 安装 v1.9.0
4. **设置 → 数据 → 导入恢复**，选刚才那个备份文件

> 密钥库和口令放在项目外的 `工具/签名/`（已被 `.gitignore` 排除），不会进仓库。
> 换电脑构建时把这两个文件带过去即可；**丢了就再也签不出同签名的包**，
> 以后升级用户就必须卸载重装 —— 建议自己留一份备份。

## 🚀 本次更新

### 1. 正式签名

不再是 debug 签名，装的时候不会再显示「来源未知」。安装包也从 11 MB 降到 **7.6 MB**
（正式构建不再打包调试工具）。

### 2. 设置页重新分区（不再是一长条）

原来所有设置挤在一页，要滑很久才能找到某一项。现在顶部多了**分类导航**：

| 分类 | 内容 |
| --- | --- |
| **外观** | 主题、字号、脉络方向、卡片配色 |
| **卡片** | 字段名称（可改名）、卡片上显示哪些信息 |
| **提醒** | 拜访提醒开关、通知自检与修复、提醒频率 / 提醒日 / 提醒时间、新客户判定 |
| **数据** | 产品库管理、导出备份、导入恢复、清空所有数据 |
| **关于** | 应用名称、宣传语、客户数 / 产品数、版本号 |

每一类都在一屏之内，进来先选类，不用再翻找。

### 3. 移除了「系统界面语言」

那一项原来放在设置里，但完整的多语言界面还没做，留着容易让人误以为能切。
**已从界面上移除**（底层代码保留，将来做完整英文版时直接接回来）。
日期选择器等系统弹窗仍会自动跟随手机的界面语言，不受影响。

## 🔍 关于「按你的手机品牌设置」

设置页里那条品牌引导，**是运行时真实检测的**，不是写死的：

```
ReminderScheduler.brand() = Build.BRAND.lowercase()
```

`Build.BRAND` 是 Android 系统提供的只读属性，取自手机的厂商信息 ——
所以：

- **iQOO 手机** → 显示「VIVO / iQOO」的步骤
- **小米手机** → 显示「小米 / Redmi」的步骤（省电策略 → 无限制）
- **华为 / 荣耀** → 显示「应用启动管理」的步骤
- **三星** → 显示「后台使用限制」的步骤
- **其他品牌** → 显示通用建议

**朋友用别的手机装上，看到的会是适配他自己手机品牌的步骤，不会是 iQOO 那套。**
检测到的是品牌（如 `vivo` / `xiaomi`），不涉及任何个人信息，也不联网。
