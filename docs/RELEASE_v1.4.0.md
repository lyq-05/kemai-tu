# 客脉图 v1.4.0

**📦 安装包：[`客脉图_v1.4.0_debug.apk`](客脉图_v1.4.0_debug.apk)**（10.9 MB）

## 这次修了什么

### 1. 点击延迟 —— 根因找到了

选中卡片、切换选中、点「n 位下级」，之前都有肉眼可见的延迟。

根因：画布注册了「双击编辑」手势。Compose 的 `detectTapGestures` 一旦有双击回调，
**每一次单击都必须先等一个 ~300ms 的双击超时**，才能确定"这不是双击"。
所以每个操作都慢了半拍。

去掉双击手势后单击立即生效 —— 编辑卡片走底部操作条的「编辑」或长按菜单，功能一点没少。

### 2. 通知不在屏幕上方弹出

你反馈"通知栏能看到，但没弹出来"。原因是通知渠道用了 `IMPORTANCE_DEFAULT`，
这个级别**只静静地进通知栏，不会横幅弹出**。

而通知渠道的重要性**创建后就不能再改**，所以只能新建一个 `IMPORTANCE_HIGH` 的渠道，
并自动清理掉旧渠道。实测确认新渠道 `mImportance=4`（HIGH）。

### 3. 电池优化那个红色感叹号

之前只是把你送到「电池优化」列表页，而且你设了厂商的「允许后台高耗电」后它还是红的 ——
因为**那是两套完全不同的设置**：

| | 管什么 |
| --- | --- |
| 厂商的「后台耗电管理 / 允许后台高耗电」 | 厂商自己的后台策略 |
| Android 标准的「电池优化」白名单 | 系统的 Doze 省电机制 |

自检页那一项读的是后者，所以厂商开关开了它仍然是红的 —— 不是误报，但确实容易让人误解。

现在改了两处：
- 点「去开启」**直接弹出系统的授权对话框**，一次到位，不用自己在列表里翻
- 文案明确写出"这和厂商的『后台耗电管理』是两套不同的设置，两个都设上才最稳"

### 4 & 5. 精确闹钟权限：会主动要，但不强制

你这条建议我完全采纳了。测试闹钟完全没反应，就是因为非精确闹钟在厂商 ROM 上
可能被无限期延后 —— 而精确闹钟能穿透 Doze。

现在：

- 应用**主动申请** `SCHEDULE_EXACT_ALARM` 权限
- 自检页新增「精确闹钟」一项，**明确告知后果**：
  > 未授权 —— 提醒仍然会发，但可能晚几分钟到几十分钟。开了它才能在省电模式下准点响
- 点「去开启」直接跳到系统授权页
- **不强制**：没授权就自动退回非精确闹钟，功能不中断
- 授权成功后系统会发广播，应用**自动改排**为精确闹钟，不用手动重启

## 安装

1. 下载上面的 APK，传到手机点击安装
2. 系统提示"不允许安装未知来源应用"时，给**文件管理器**开权限后继续
3. 首次打开是**干净的空画布**，点中间的「新建第一位客户」开始

### 装完建议先做这三件事

1. **设置 → 提醒 → 通知是否正常？** —— 把「系统电池优化」和「精确闹钟」两项点开
2. 按页面下方**给你的机型（VIVO / iQOO）**的引导，把「允许后台高耗电」设上
3. 点「**测试闹钟**」，把手机放一边等一两分钟，看通知会不会自己弹出来
