## 🚀 本次更新

### 修复：v1.8.0 的「上一次闹钟」本身不可信

用户反馈：**通知都弹出来了，那一行却还写着「还没有触发记录」**。

**原因**：那一行只在页面组合时读一次值。用户点进应用的那一刻闹钟还没响，
界面早就组合完了；等闹钟真的响了、通知弹出来了，界面**不会重新读**，
于是一直停在旧值上。

**修法**：

- 诊断数据现在**每秒自动刷新**，闹钟响的那一瞬间就能在页面上看到结果
- 新增 **「本次排定」** 一行 —— **不用等它响**，排完就能看出这次用的是什么闹钟，
  有没有被降级
- **「上一次闹钟」改成显示「预定 X → 实际 Y（误差）」**，例如：

  ```
  上一次闹钟
  预定 9月30日 23:23 → 实际 9月30日 23:23（准点（误差 5 毫秒））
  ```

  一眼就能判断到底是"闹钟没响"还是"响了但被延迟"。

### 加强：VIVO / iQOO 的后台设置引导

原来的引导只说「允许后台高耗电」，**漏了同样关键的「自启动」** ——
在 VIVO 上这是**两个独立的开关**，而「自启动」才是后台广播（闹钟到点）能不能送达的关键。

现在引导里明确列出三个独立开关，并注明只设第一个不够。

## 🔍 关于「精确闹钟是不是默认开启」

用户问得对，这里说清楚：

| 机制 | 是否需要用户操作 |
| --- | --- |
| `USE_EXACT_ALARM`（v1.8.0 新增声明） | **Android 13+ 安装即自动授予，不需要用户做任何事** |
| `SCHEDULE_EXACT_ALARM`（旧机制） | 需要用户手动去系统设置里开，v1.8.0 起仅作为 Android 12 的兜底 |

所以自检页里「精确闹钟 ✓ 已授权」是**应用自己拿到的**，不是用户设的。

**但**：拿到这个权限只保证"应用可以排精确闹钟"，
**不能保证厂商的后台策略一定不拦**。这两件事是分开的 ——
厂商那层要靠自检页里的「厂商后台策略」引导去设。

## ⚠️ 升级说明

- **直接覆盖安装即可**，数据不会丢
- 升级后请这样验一次，用数据说话：
  1. 进 **设置 → 提醒 → 通知自检与修复**
  2. 看 **「本次排定」** —— 应该显示 **「闹钟式（最可靠，不怕省电策略）」**
  3. 点「1 分钟后发一条通知」→ **按 HOME 切后台** → 等一分钟
  4. 回来（或者看到通知就点进来）看 **「上一次闹钟」** 那行：
     - 显示 **「准点（误差 N 毫秒）」** = 系统没拦
     - 显示 **「晚 N 分钟」** = 被厂商策略延迟了，需要按下面引导设自启动
     - 显示 **「还没有触发记录」** 但时间早过了 = 闹钟压根没送达
