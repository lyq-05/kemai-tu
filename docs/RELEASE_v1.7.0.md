## 🚀 本次更新

### 修复：设置里谎报「一切正常」

你反馈得很准：「通知自检与修复」右边写着**一切正常**，可点进去明明还有电池优化、精确闹钟在报警。

**根因**：那个状态只查了「通知权限」一项就下结论了。现在改成**汇总全部可检查项**：

| 计入状态的检查项 | 说明 |
| --- | --- |
| 通知权限 | 没开就发不出通知 |
| 系统电池优化 | 没进 Doze 白名单，后台可能被冻结 |
| 精确闹钟 | 没授权，提醒可能晚几十分钟 |
| 通知能不能弹出来 | 渠道级别不够高，不会横幅弹出 |

「厂商后台策略」系统读不到，不计入。

现在显示的是真实数字：

- 全部就绪 → **一切正常**（普通灰）
- 有 N 项没弄好 → **N 项待处理**（琥珀色 `#B4632A`，一眼能看到）

### 新增：首次进入就引导把提醒设置好

你说得对 —— **这些东西不该等用户自己翻到设置里才发现**，那时候可能已经漏掉一次提醒了。

现在首次进入会连着给两个提示：

1. 「先看一眼操作指南？」→ 查看指南 / 忽略
2. 「**顺便把提醒设置好？**」→ 现在去设置 / 以后再说

第二个提示会**先检测一遍**，只有真的还有没弄好的项才弹，并写清楚：

> 检测到还有 N 项系统设置没弄好（通知权限 / 电池优化 / 精确闹钟 / 通知能否弹出）。
> 不设置的话，到点可能收不到系统通知 —— 不过顶部「拜访 n」的角标始终准确，不会漏跟。
> 现在花一分钟配好，以后就省心了。

两个提示都只出现一次，之后不再打扰。
