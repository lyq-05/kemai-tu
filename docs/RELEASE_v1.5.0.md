## 🚀 本次更新

### 新增：卡片上显示什么，自己选

设置 → **卡片显示**，四个开关随便点：

| 可显示的内容 | 说明 |
| --- | --- |
| 办卡时间 | 默认开 |
| 使用过的产品 | 多个产品用「·」连起来 |
| 手机号 | 新增的字段，见下 |
| 备注 | 只取第一行 |

- **客户少**的时候可以全开，一张卡片上信息一览无余
- **客户多**的时候只留名字，整张图清爽好认
- 关掉后**卡片会立刻变矮**，布局自动重排
- 还有「**只看名字**」「**全部显示**」两个快捷按钮，一键切换

> 客户名称**始终显示**，不用选。另外图缩小到一定程度时，卡片也会自动只留色块 ——
> 这是早就有的细节分级，和这个开关是两回事。

### 新增：手机号字段

编辑面板多了一个「手机号」，和办卡时间、产品一样可以留空。
它的名字也能改（设置 → 字段名称 → 手机字段 → 比如改成「联系电话」）。

**列表示例**（开了「全部显示」之后）：

```
┌─────────────────┐
│     客户A       │
│  2026年9月20日  │
│  金卡 · 白金卡  │
│   13801234567   │
└─────────────────┘
```

### 改进：测试按钮改名叫「1 分钟后发一条通知」

之前叫「测试闹钟」，容易让人以为是闹钟那种全屏响铃。**其实它不是** —— 说明一下：

| | 客脉图的「提醒」是什么 |
| --- | --- |
| **形态** | 一条**系统通知**：屏幕上方横幅弹出 + 提示音，点它进拜访清单 |
| **对比** | 和微信消息是一个形态，**不是**闹钟那种全屏响铃的界面 |
| **为什么** | 这是「每周该跟进哪些客户」的提醒，不是必须立刻处理的事，用通知更合适 |

现在按钮和说明文案都写清楚了，并且明确提示：
**按下之后可以切后台、或者从最近任务里划掉应用**，看通知还会不会准时来 ——
这正是真实的每周提醒会经历的场景。

## 🚨 已知问题

- **没有精确闹钟权限时，通知可能晚几分钟到几十分钟**。这是 Android 省电机制的预期行为。
  想准点就到「通知是否正常？」里把精确闹钟开了
- 开了「全部显示」但某位客户没填对应信息时，那一行会留空（卡片保持统一高度，不会参差不齐）
