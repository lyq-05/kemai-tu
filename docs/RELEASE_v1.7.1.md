## 🚀 本次更新

### 修复：点「查看指南」后，第二条提示会盖在指南上面

v1.7.0 加了两个首次引导，但顺序有个明显漏洞：

用户点「查看指南」后，界面会切到操作指南页；而"顺便把提醒设置好？"的判断条件
在同一帧就满足了，于是**对话框直接盖在用户正要看的指南上面** ——
人家刚说要看，你就把内容挡住了。

**修法**：第二条提示**只在回到主界面（画布）时才问**。现在两条路径都顺了：

| 用户操作 | 现在的行为 |
| --- | --- |
| 点「忽略」 | 人还在画布上 → 第二条**立刻**弹出来，一次把该说的话说完 |
| 点「查看指南」 | 安静地进指南页，**不打扰**；等他看完按返回、回到画布，第二条才出现 |

同时补了两个保险：搜索框打开、或客户编辑面板打开时，也不会弹。
