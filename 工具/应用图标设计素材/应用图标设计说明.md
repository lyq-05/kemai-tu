## 二、这个应用是干什么的

打开应用就是一张**客户脉络图**：

- 每一位客户是图上的**一个卡片**
- 谁介绍来的，就**挂在谁的下方**（形成层级）
- 同一级的客户**横向并排**
- 图可以**无限延展**，上下左右都没有边界

除了画图，它还有一份**拜访清单**：按客户办卡时间自动算出"最近要跟进的客户"，
每周提醒一次，拜访完打勾并留下记录。

**一句话：它是一张会生长的客户关系地图。**

整体是这个调性：

| 功能图标 | 自绘细线描边（1.7px 圆角端点），不用填充式图标 |

可以用它作为起点改造，也可以完全重新设计。

## 四、设计诉求

请设计一个**桌面图标**，需要传达：

1. **「关系」** —— 节点与节点之间的连接（这是产品的灵魂）
2. **「图」** —— 它长成一张网 / 一张地图，不是一条列表
3. **克制** —— 一眼看懂，不要塞太多细节；缩到 48px 还要认得出

### 建议方向（任选或另辟蹊径）

| 方向 | 说明 |
| --- | --- |
| **A. 节点网络** | 3–5 个圆点用折线连成一张小树/小网，直接呼应产品形态。最稳。 |
| **B. 汉字「脉」** | 单字图形化。国风、有质感，与"客脉图"的"脉"字呼应。 |
| **C. 脉 + 节点** | 用一条有分支的"脉络"曲线，末端是客户节点。把 A 和 B 融合。 |
| **D. 卡片树** | 抽象成几个小方块挂在树枝上，更像"卡片挂在导图上"。 |

### 配色建议

- 主色用**青瓷蓝绿 `#2F6E6A`**，与 App 内强调色一致
- 可搭配浅色底 `#FBFAF7` 或米白，避免高饱和撞色
- 若要更醒目，可用深色底 `#14181A` + 青绿图形

## 五、交付规格

| 项目 | 要求 |
| --- | --- |
| 尺寸 | **1024 × 1024** PNG，主体居中占 **60%** 左右，四周留白 |
| 格式 | PNG，背景可透明 |
| 安全区 | Android 自适应图标会裁切：**中心 66% 的圆形/方形区域内必须放得下主体**（按 108dp 画布算，中心 72dp 是安全区），四角内容可能被裁掉 |
| 深色/浅色 | 最好主体在浅色和深色背景上都清晰；如果做不到，给**两个版本**（浅色版、深色版）我来处理 |
| 可选 | 顺带给一版**纯单色剪影**（用于通知栏小图标） |

**可交付形式**（二选一）：
- 直接给 1024×1024 的成品图，我来切成各密度 + 自适应图标
- 或者给前景层 / 背景层两张 432×432 的图

## 六、不要什么

- ❌ 不要写实 3D、不要金属质感、不要投影拉丝
- ❌ 不要塞入文字（除方向 B 的单字「脉」以外）
- ❌ 不要用高饱和的红黄蓝大撞色
- ❌ 不要细到 48px 就糊成一团的细节
